# Mac Shortcut Parcours

Learn macOS keyboard shortcuts by doing them, inside a practice Mac in your browser.

Open `index.html` in a browser on your Mac. Each step gives you a task ("Close the Pasta recipes tab", "Empty the Trash") and the practice Mac reacts to the shortcut you press: tabs close, text gets selected, files move to the Trash.

**How to press shortcuts without your real Mac reacting:** tap the modifiers one at a time (press and let go), then press the last key. For ⌘W: tap ⌘, let go, press W. The keys are never held together, so macOS ignores them. Use the on-screen fn key for fn/Globe shortcuts.

## Stages

1. Editing basics (TextEdit): select, copy, paste, undo, bold, save, print
2. Moving through text: line/word/document jumps, selecting, deleting, Find
3. Tabs & windows (Safari): new/close/reopen tabs, switching, windows, private window
4. Browsing: address bar, back/forward, reload, zoom, bookmarks, history, dev tools
5. Files in Finder: Quick Look, duplicate, Trash, new folder, rename, views
6. Getting around Finder: Home, Applications, Desktop, Documents, Downloads, Go to Folder, path bar
7. Apps & desktop: app switcher, Spotlight, hide, minimize, full screen, tiling, Mission Control, Spaces, lock
8. Screenshots & system: all screenshot modes, emoji, Notification Center, Control Center, Quick Note

Each stage is scored with up to 3 stars (fewer hints and wrong shortcuts = more stars). Progress is saved in your browser.

`flashcards.html` is the simpler flashcard version: read the action, type the shortcut.
